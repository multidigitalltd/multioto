מחבר את אתר הוורדפרס לפאנל התפעול של Multi Digital: נקודת קצה MCP מאובטחת
לאבחון ותיקון מרחוק.

== מאיפה מורידים את קובץ ה-ZIP ==

הדרך הקלה: בפאנל, במסך האתר, לוחצים "הורד תוסף (גרסה אחרונה)" — מקבלים את ה-ZIP.
(גם ב-repo: wordpress-plugin/releases/multioto-agent-<גרסה>.zip, ובנייה מחדש: wordpress-plugin/build.sh.)

== התקנה וחיבור ==

כל הקודים מוכנים בפאנל — רק מעתיקים אותם לתוסף. אין צורך להמציא מפתח או טוקן.

1. בפאנל: הורידו את התוסף ("הורד תוסף") והתקינו באתר ("תוספים → הוסף חדש → העלאת תוסף") והפעילו.
2. בפאנל, במסך האתר, לחצו "קודי חיבור לתוסף" — ייפתח חלון עם מפתח MCP (וטוקן עדכון אם צריך) מוכן להעתקה.
3. באתר, ב"הגדרות → Multi Digital Agent": כתובת הפאנל כבר מוגדרת מראש — הדביקו רק את מפתח ה-MCP (וטוקן העדכון אם ניתן) ושמרו.
   (מפתח MCP חייב להיות זהה לזה שבפאנל — פשוט מעתיקים אותו.)
4. בפאנל: ודאו ש"חיבור פעיל" דלוק ולחצו "בדוק חיבור AI".

== אבטחה ==

* כל בקשה מהפאנל מאומתת במפתח ה-MCP (השוואת hash בזמן קבוע).
* התוסף חושף רשימה סגורה של פעולות בלבד — אין הרצת קוד/SQL/קבצים שרירותית.
* קריאת הגדרות מוגבלת לרשימת מפתחות בטוחה (ללא סודות/PII).
* שינויים (עדכון/הפעלה/כיבוי תוסף, ניקוי מטמון) מבוצעים רק לאחר אישור מנהל
  בפאנל — התוסף עצמו לא יוזם דבר.

== עדכון עצמי ==

התוסף בודק מול הפאנל אם יש גרסה חדשה ומתעדכן דרך מנגנון העדכונים הרגיל של
וורדפרס, ומפעיל עבור עצמו את עדכוני הרקע האוטומטיים — כך שגרסה חדשה מותקנת
באתר לבד, בלי לחיצה ידנית ובלי התקנה מחדש בכל אתר.

== Cloudflare חוסם את החיבור (אתגר "Just a moment") ==

אם "בדיקת החיבור" בפאנל נכשלת עם 403 ובאתר פעיל Cloudflare, סביר ש-Cloudflare
מגיש אתגר JavaScript לבקשות מהפאנל (הפאנל הוא שרת ואינו יכול לפתור אתגר כזה).
הפתרון: ב-Cloudflare של האתר יוצרים כלל WAF שמדלג (Skip) על האתגרים לכתובת
‎/wp-json/md-agent/*‎, או מתירים את כתובת ה-IP של הפאנל. (אין להשבית את
Cloudflare באתר כולו — די בחריגה לנתיב הזה.)

== שרתים שמסירים את כותרת Authorization ==

חלק מהשרתים (PHP-CGI/FastCGI) מסירים את כותרת Authorization. אם "בדיקת החיבור"
נכשלת עם 401 למרות מפתח נכון, הוסיפו ל-.htaccess:

  RewriteEngine On
  RewriteCond %{HTTP:Authorization} ^(.*)
  RewriteRule .* - [E=HTTP_AUTHORIZATION:%1]

== Changelog ==

= 1.2.0 =
* **סוגי תוכן מותאמים.** כלי התוכן עבדו עד היום רק על עמודים ופוסטים, בזמן שהתוכן האמיתי באתרים רבים יושב בסוגים מותאמים — נכסים, פרויקטים, אירועים. כל סוג תוכן רשום באתר נתמך עכשיו, ונוסף wp_post_types_list שמראה אילו סוגים קיימים, כמה פריטים בכל אחד והאם יש לו שדות מותאמים. סוג שאינו קיים נדחה בשמו, במקום ליפול בשקט לעמודים ולהחזיר תשובה שנראית תקינה.
* **שדות מותאמים (ACF ו-JetEngine).** wp_fields_schema מראה אילו שדות מוגדרים לסוג תוכן — מפתח, תווית ואפשרויות — כדי שאפשר יהיה לכתוב למפתח הנכון; wp_fields_get ו-wp_fields_update קוראים ומעדכנים. כשה-ACF פעיל העדכון עובר דרך ה-API שלו, כדי שתאריך יישמר כפי ש-ACF שומר תאריך ולא כטקסט שהוא לא יידע לקרוא. שדות פנימיים (מתחילים בקו תחתון) חסומים לכתיבה.
* **עריכת טקסטים באלמנטור.** עמוד אלמנטור אינו שומר את התוכן שלו ב-content הרגיל, ולכן עריכה שם שינתה עותק שאיש אינו רואה ודיווחה על הצלחה. wp_elementor_texts_get מחזיר את כל הטקסטים שבעמוד עם מזהה הרכיב של כל אחד, ו-wp_elementor_text_update מחליף אחד מהם ומרענן את ה-CSS של העמוד. **טקסט בלבד** — שינוי מבנה, עיצוב או סדר רכיבים אינו נתמך בכוונה, כי עריכה חופשית של מבנה העמוד היא הדרך המהירה לשבור עמוד שלקוח שילם עליו.
* **כתיבה לווקומרס.** חיפוש מוצר בטקסט חופשי, עדכון מחיר, מבצע עם תאריכים, מלאי וסטטוס, יצירת מוצר (תמיד כטיוטה), ויצירה וסיום של קופונים. הכל דרך אובייקטי ה-CRUD של ווקומרס ולא דרך meta, כדי שהמחיר המוצג והמחיר בקופה לא ייפרדו זה מזה. מחיר מבצע שאינו נמוך מהמחיר הרגיל נדחה במקום להתקבל כ"הנחה" של אפס.
* **כל כלי כתיבה מחזיר את המצב הקודם.** זו התשתית ל"בטל" בצד הפאנל: שינוי שאי אפשר להחזיר הוא שינוי שאין לעשות מהטלפון.
* רכיבים מרובי-שורות באלמנטור (אקורדיון, טוגל, טאבים, רשימות) נתמכים דרך נתיב שדה כגון tabs.0.tab_title — הטקסט שלהם יושב בשורות ולא בהגדרה ישירה, ובלי זה הם היו מוצעים לעריכה ולעולם לא נמצאים.
* עדכון שדות מותאמים מאמת את כל המפתחות לפני שהוא כותב ולו אחד: סירוב חייב להיות סירוב שלא נגע באתר, ולא כתיבה חלקית שמדווחת כשגיאה ואינה מותירה דרך חזרה.
* תאריכי מבצע וקופון נקראים בשעון של החנות ולא ב-UTC — מבצע שהתבקש להסתיים "ב-20" היה מסתיים ב-03:00 בבוקר ה-20 שעון ישראל.
* חיפוש מוצר מוצא גם לפי מק"ט מדויק, ולא רק לפי טקסט בכותרת ובתיאור.
* רשימת התוכן מציינת לכל עמוד אם הוא בנוי באלמנטור, ולא רק הקריאה של עמוד בודד — כדי שאפשר יהיה לדעת זאת בלי לשלוף ארבעים עמודים אחד-אחד, ובלי לנחש.
